What is new in V6

USB-C16-pin USB 2.0 receptacle with separate 5.1 k on CC1 and CC2: works with USB-C to USB-C cables, laptops and phone chargers.
Safe 1.8 - 5.5 V targets74LVC8T245 + 74LVC1T45 level shifter powered from the target's own VCC: no more 5 V signals into a 3.3 V chip.
Pins released when idleThe shifter outputs are only on while the red BUSY LED is lit, so the programmer does not fight the target's own use of MOSI / SCK / RST.
Protected target powerJumper for 5 V / 3.3 V / off, 200 mA PTC fuse and a yellow LED: a shorted target no longer resets the programmer or the PC port.
USB protection500 mA PTC on VBUS and a USBLC6 ESD diode array on D+ / D-.
10-pin AND 6-pin ISPKeyed box header for the standard 10-pin cable plus the 6-pin Arduino ICSP layout, as asked in the v5 comments.
Easy firmware updateA separate 6-pin header (J4) to flash the board's own ATmega8A; no more jumper juggling on the ISP header.
Stock firmwareRuns the original USBasp 2011-05-28 firmware unchanged and works with avrdude (-c usbasp) and the Arduino IDE.
