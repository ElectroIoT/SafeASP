Setup in EasyEDA

1. Open EasyEDA Pro (web), new project SafeASP (USBasp V6) with one schematic and one PCB.
2. Make 3 schematic sheets named as above (1_USB_POWER, 2_MCU, 3_SHIFT_ISP).
3. Place parts by searching the LCSC number (C#) in the library search; set the Designator to the Ref in the table.
4. Use net labels for every connection that leaves a page; use the same name on both pages. Names are case-sensitive.
5. Run the schematic check after each page and fix every warning.

4. R3 68 R from USB_DP_J to USB_DP, R4 68 R from USB_DN_J to USB_DN. D1 zener: cathode USB_DP, anode GND. D2 zener: cathode USB_DN, anode GND. R5 2.2 k from +5V to USB_DN.
5. U3 AP2112K: pin 1 VIN and pin 3 EN to +5V, pin 2 GND, pin 5 VOUT to +3V3, pin 4 No-Connect. C8 10 uF on +5V, C9 10 uF on +3V3.
6. JP1 1x3: pin 1 +5V, pin 2 VTGT_SUP, pin 3 +3V3. F2 PTC 200 mA from VTGT_SUP to VTGT. R9 1 k from VTGT_SUP to LED3 (yellow) anode, cathode to GND.

Sheet 3: Level shifter and ISP headers

Target-side nets end in _T. VTGT is both the target supply (when JP1 is fitted) and the level-shifter supply: no voltage on ISP pin 2 = outputs off.

Both VCC pins of U4 (23, 24) must be connected.

Final checks

1. Every net label is used at least twice. One GND, one +5V, one +3V3, one VTGT.
2. Compare the part count with the BOM page (45 pieces).
3. Compare every footprint with its datasheet before the layout: C165948 USB-C, TQFP-32 (0.8 mm pitch), TSSOP-24, SC-88, 3225 crystal, box header key position.
4. Check USB_DP is on BOTH U1 pin 13 and pin 32.
5. Export the schematic PDF and send it for a check.
